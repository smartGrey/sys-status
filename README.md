# 网速

Apple Silicon Mac 的菜单栏网速表，每秒更新。上排是上传，下排是下载。B、K、M、G 表示每秒字节数，按 1000 进位。

**两枚箭头同时变绿**表示这台 Mac 按当前系统网络设置，最近一次访问 Google 连通性检测地址成功。应用每 2 秒请求一次 `https://www.google.com/generate_204`，直接收到 HTTP 204 即变绿。等待首次结果、请求失败或超过 5 秒时，箭头使用普通文字色。直连、系统代理和 TUN 均以实际请求结果为准。仅供浏览器插件或手动指定的代理只影响使用它的程序。

检测复用连接，同时最多一个请求在途，睡眠时暂停。M1 Max 接电短测中，相比只采集网速，检测进程平均增加约 0.07 个百分点的单核 CPU 占用和 3 MB 内存。清醒联网 8 小时约请求 14,400 次，按实测的稳定连接复用开销折算，应用与本机代理之间共约 2.4 MB。重新握手、代理外层封装和重传会增加网卡实际流量。

需要 macOS 26 或更高版本。安装 Xcode 后，在项目目录运行以下命令。

```sh
./scripts/build.sh
open ./网速.app
```

日常使用可将 `网速.app` 放到「应用程序」。左键或右键点菜单栏读数，可切换「登录时启动」（默认关闭）或退出。
