# 网速

适用于 Apple 芯片 Mac（macOS 26 或更高版本）的菜单栏工具，每秒更新上传和下载网速。悬停可查看站点探测结果、耗时和近 5 分钟成功率，箭头颜色汇总已启用站点的状态。

## 使用

- 在菜单里打开「探测站点配置」，添加 HTTPS 地址或 TCP 端口。HTTPS 支持复用连接和新建连接，TCP 只检查主机端口能否建连，例如 NAS 的 `nas:445`。
- 新增站点默认停用。在站点子菜单勾选「启用此站点」并选择探测强度。在配置窗口点「应用」可继续编辑，点「保存」会保存并关闭窗口。
- 站点配置位于 `~/Library/Application Support/NetRate/config.json`。外部修改后，在配置窗口选择「配置文件 → 重新读取配置」。
- 菜单还提供「登录时启动」和「禁用系统睡眠」。首次禁用睡眠时，按提示在「系统设置 → 通用 → 登录项与扩展」中批准后台服务。
- 勾选「音量键微调」后，普通音量加减键使用系统 Option + Shift 的细步长。首次使用时，请在系统设置的「隐私与安全」中为「网速」授权辅助功能（部分系统称为「设备控制和数据访问」），再点一次开关。应用会记住选择。如果菜单显示「需重新启用」，悬停可查看原因。
- 「统计文本行数」可统计单个文件或项目总行数。展开「目录详情」可按名称查看文件和子目录，勾选要计入总数的项目。
- 「清理 Mac 附加文件」递归删除所选目录中的 `.DS_Store` 和 AppleDouble 格式的 `._` 文件，并显示两类各自的清理数量和总数。

## 构建与测试

安装 Xcode 后，在项目目录运行以下命令。日常使用可将生成的「网速.app」放到「应用程序」。

```sh
./scripts/build.sh
open ./网速.app
xcodebuild -project NetRate.xcodeproj -scheme NetRate -destination 'platform=macOS,arch=arm64' test
```
