# 状态栏扩展

适用于 Apple 芯片 Mac（macOS 26 或更高版本）的菜单栏工具。实时显示上传和下载网速，悬停可查看 HTTPS 和 TCP 探测的耗时及近 5 分钟成功率。菜单还提供秒表、环境音监听、系统状态、音量键微调、睡眠控制、文本行数统计和 Mac 附加文件清理。

将仓库根目录的 `状态栏扩展.app` 复制到「应用程序」即可使用。

## 配置

配置保存在 `~/Library/Application Support/NetRate/`。站点、秒表、环境音、系统状态、音量键和状态栏模块顺序分别对应 `config.json`、`stopwatch.json`、`hearing.json`、`system-status.json`、`volume-keys.json` 和 `status-bar.json`。

HTTPS 站点可直接填写 `example.com/health`，TCP 站点分别填写主机和端口。手动修改站点配置后，在探测站点配置窗口选择「配置文件 → 重新读取配置」。

悬停状态栏入口预览，左键打开面板，右键打开总菜单。点击图钉或拖动背景可固定面板，再点图钉收起。勾选「系统状态」可查看电池、内存、启动盘、温度、算力和默认音频设备。温度卡片显示整机热压力及可读取的风扇转速。在「状态栏指标」中拖动电池或其他指标可调整顺序和显隐，至少保留一项。点击指标色块可配色。「偏好设置」统一控制状态栏和总菜单的模块顺序。

「网络状况」同时开关网速和站点探测。网络面板显示 Wi-Fi 信号和无线发送速率。「公网测速」依次测下载、上传，期间暂缓发起站点探测。点击站点名称切换探测强度，「显示所有站点」可找回暂停的站点。「探测配置」打开完整设置，「立即探测」刷新已启用的方式。

## 构建与测试

安装 Xcode 后，在项目目录运行以下命令。

```sh
./scripts/build.sh       # 构建并更新根目录的签名 App
./scripts/test.sh        # 日常快速测试
./scripts/test.sh full   # 完整回归测试
```
